# Fitness Lifestyle

Fitness Lifestyle is a web application developed as part of my bachelor's thesis. The application helps users maintain a healthy lifestyle by providing trainer reservations, a BMI calculator, a food database and blog management.


## Features

- User registration and login
- Role-based authentication (User, Trainer, Administrator)
- Trainer reservation system
- Blog management
- BMI calculator
- Food database imported from CSV
- Food database accessible through a PHP JSON API
- Contact form
- Responsive design for desktop and mobile devices


## Technologies

- PHP
- JavaScript
- HTML5
- CSS3
- MySQL
- Apache (XAMPP)

## Installation

1. Install XAMPP.
2. Copy the project into the `htdocs` folder.
3. Create a MySQL database named `fitnesslifestyle`.
4. Import the provided `fitnesslifestyle.sql` file.
5. Start Apache and MySQL.
6. Open your browser and visit:

http://localhost/FitnessLifestyle/
