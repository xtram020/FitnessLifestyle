Typ aplikace: webová aplikace
Autor: Duc Minh Tran
Rok: 2026

Popis aplikace:
Aplikace Fitness Lifestyle byla vytvořena jako praktická část bakalářské práce.
Jedná se o webovou aplikaci zaměřenou na fitness a zdravý životní styl.
Aplikace je určena ke spuštění v lokálním prostředí pomocí programu XAMPP a webového serveru Apache.

Požadavky na spuštění:

XAMPP
Apache
MySQL 
webový prohlížeč

Umístění projektu:
Složka projektu musí být umístěna do adresáře:

\xampp\htdocs\

Postup spuštění aplikace:

1. Nainstalujte a spusťte program XAMPP.
2. V ovládacím panelu XAMPP spusťte moduly Apache a MySQL.
3. Zkopírujte složku projektu "Fitnesslifestyle" do adresáře:
   \xampp\htdocs\
4. Do webového prohlížeče otevřete localhost/phpmyadmin/
5. Vytvořte databázi s názvem:
   fitnesslifestyle
6. Importujte přiložený databázový soubor (.sql).
7. Otevřete webový prohlížeč.
8. Do adresního řádku zadejte:

http://localhost/Fitnesslifestyle/index.php

Poznámka:
Aplikace byla vyvíjena a testována v lokálním prostředí pomocí XAMPP.
Pro správnou funkčnost je nutné mít spuštěný webový server Apache a případně databázový server MySQL.
